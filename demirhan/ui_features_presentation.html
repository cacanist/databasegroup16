Q1: Analytics
Visitor Browser Matrix
01 / 06
Reporting
 SQL: visitors_browser_matrix.sql
SELECT
    v.Visitor_ID, v.VisitorType,
    cr.Region_ID, v.Country,
    bi.Browser_ID       AS Browser,
    bi.BrowserVersion
FROM       VISITOR        v
JOIN       COUNTRY_REGION cr
    ON  v.Country     = cr.Country
LEFT JOIN SESSION        s
    ON  v.Visitor_ID  = s.Visitor_ID
LEFT JOIN SYSTEM_CONFIG  sc
    ON  s.Config_ID   = sc.Config_ID
LEFT JOIN BROWSER_INFO   bi
    ON  sc.Browser_ID = bi.Browser_ID
ORDER BY v.Visitor_ID;

Q2: Analytics
Unique Monthly Visitors
02 / 06
Seasonality
 SQL: monthly_unique_visitors.sql
SELECT
    tc.Month,
    mi.Quarter,
    COUNT(DISTINCT s.Visitor_ID)
        AS Visitor_Count
FROM      TIME_CONTEXT tc
JOIN      MONTH_INFO   mi
    ON  tc.Month   = mi.Month
JOIN      SESSION      s
    ON  tc.Time_ID = s.Time_ID
GROUP BY tc.Month, mi.Quarter
ORDER BY Visitor_Count DESC;

Q5: Compliance & Security
Surgical User Deletion
05 / 06
GDPR Safe
 SQL: delete_visitor_cascade.sql
-- Step 1: Nullify suggestion credits given to others
UPDATE SESSION
SET   SuggestedBy = NULL
WHERE SuggestedBy = 1;

-- Step 2: Remove page visit records
DELETE FROM PAGE_VISIT
WHERE Session_ID IN (
    SELECT Session_ID FROM SESSION
    WHERE  Visitor_ID = 1
);

-- ... Steps 3–6: metrics, activity,
--     sessions, suggestions removed ...

-- Step 7: Remove the visitor record
DELETE FROM VISITOR
WHERE Visitor_ID = 1;
7 step bottom up deletion order
1
Nullify SuggestedBy references in SESSION
2
Delete PAGE_VISIT records
3
Delete PAGE_METRICS records
4
Delete ACTIVITY_LOG records
5
Delete SESSION records
6
Delete SUGGESTION records
7
Delete VISITOR profile
Referential integrity remains 100% intact. No orphaned records. No accidental page deletions.
Insight: A 7-step bottom-up deletion protocol safely unwires all user footprints without violating foreign key constraints: surgical, compliant, and irreversible.
